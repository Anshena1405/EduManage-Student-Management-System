# EduManage - Student Management System

EduManage is a web-based Student Management System developed using HTML, CSS, JavaScript, Firebase, and Chart.js. It provides separate portals for teachers and students to manage academic activities efficiently.

## Features

### Teacher Portal
- Teacher dashboard overview
- Student management
- Attendance management
- Course management
- Allocate marks
- Timetable scheduling
- Exam scheduling
- Assignment management
- At-risk student monitoring
- Notifications and feedback
- Performance prediction section

### Student Portal
- Student dashboard overview
- View marks
- View attendance
- Study hub
- Submit assignments
- Timetable and exam details
- Notifications
- Feedback submission
- Personal performance radar chart

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase
- Firestore Database
- Chart.js
- Font Awesome
- Antigravity IDE

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any browser.
4. Use the Teacher Portal or Student Portal to access the system.
